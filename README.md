A small Python command-line calculator used to demonstrate Git branching, merging and merge-conflict resolution.

Usage: python calculator.py  (supports + - * / ^ power and % modulo)

## Git workflow
- Branches `feature-power` and `feature-modulo` both edit the same lines of README.md.
- Merging the second branch caused a merge conflict, which was resolved by keeping both features.
- Tests: python -m unittest -v
